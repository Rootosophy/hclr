## 摘要

AI能生成大量内容，但"生成得多"不等于"做得好"。同样一段AI输出，不同使用者处理方式完全不同：有人照单全收，有人逐句润色，有人只提出三五条关键判断，却让成果发生方向性改变。

HCLR（Human Cognitive Leverage Ratio，人类认知杠杆率）是一种面向AI使用者的自我评估方法。它记录从AI初稿到最终成果的全过程，观察使用者的**稀疏认知介入**（少量但关键的人类判断）对模型输出产生了多大影响，并通过**双重确认**跟踪成果是否真正被采纳、是否获得受众认可。

## 1. 为什么需要HCLR

现有工具大多只记录"是否满意"（点赞/点踩），无法回答：

- 使用者是否真正改变了AI的输出？
- 改变发生在哪个层面——措辞、局部内容、结论、整体方案，还是问题框架？
- 使用者投入了多少关键判断，才让成果达到可采纳？
- 一段时间后，使用者是否越来越能以更少的介入产生更大的有效改变？

HCLR尝试为这些问题提供一种轻量、可持续的记录与观察方法。

## 2. 核心定义

**HCLR是一种面向AI使用者的稀疏介入能力自我评估方法。** 在给定AIGC模型、任务领域和观察周期内，使用者记录自己通过有限的显性介入使生成成果发生的改变，并进行两轮确认。

形式化条件表示：

```
HCLR(u | m, d, T)
```

- `u`：使用者
- `m`：模型及版本（相对稳定的工具环境）
- `d`：任务领域
- `T`：观察周期

**模型视为既定工具环境。** 不要求完全剥离人与模型的贡献，但更换模型、任务领域或受众时应标记序列断点。

### 过程链

```
O0 → h → O1 → C1 → C2
```

| 符号 | 含义 |
|---|---|
| `O0` | 原始生成（无介入条件下的初始输出） |
| `h` | 人类介入（主动、自主的关键判断） |
| `O1` | 介入后成果（最终交付物） |
| `C1` | 第一轮确认：使用者确认是否采纳 |
| `C2` | 第二轮确认：根据真实受众反馈确认是否认可 |

## 3. 如何记录

### 3.1 基本记录单元：任务事件

基本计算单位为**任务—成果转换事件**（任务事件）：一个明确的AI协作任务，从原始生成开始，经过若干人类介入，形成可确认的最终成果。单条介入不单独作为计算单位，避免把同一成果改变重复归因。

### 3.2 记录字段

- `task_id`、`domain`（领域）、`model`（模型及版本）、`audience`（受众类型）
- `O0`（原始生成，冻结不可覆盖）、`O1`（最终成果）
- `interventions[]`（介入列表：文本、类型、时间）
- `I`（介入量）
- `C1`（0/0.5/1）、`C2`（0–1/百分比/待确认）、`C2_source`（user/landing/auto_timeout/auto_confirm）、`C2_note`（确认依据）
- 时间戳（创建/第一轮确认/第二轮确认）

完整字段定义见 [`schema/hclr-record.schema.json`](schema/hclr-record.schema.json)。

### 3.3 人类介入

介入是使用者**主动、自主**发出的关键判断，例如：事实纠正、目标或范围调整、约束补充、结论修正、分析框架改变、风格与受众适配。

两条原则：

1. **介入必须主动**：AI不得通过主动学习（Active Learning）机制决定人的审查配额、介入对象或介入边界；
2. **稀疏是事后观察属性**：不是AI预先分配的反馈预算。

### 3.4 介入量（I）

三种口径，记录时声明采用哪一种：

| 口径 | 定义 | 说明 |
|---|---|---|
| Token/字数 | 介入文本Token或字符数 | **自动记录默认**（客观、零标注负担） |
| 判断数 | 独立语义判断/关键意见条数 | 人工记录默认 |
| 次数 | 介入操作次数 | 最简单 |

> 重要边界：显性介入量不等于完整认知投入（审阅、搜索、核查、推理成本未计入）。HCLR衡量的是"显性介入杠杆"，不是完整的认知能力得分。

### 3.5 双重确认

**第一轮 C1**（生成阶段）：使用者确认本人是否采纳——`1` 采纳 / `0.5` 部分采纳（有少量修改）/ `0` 不采纳。

**第二轮 C2**（成果触达受众后）：使用者根据真实反馈确认受众是否认可——`1` 认可 / `0.5` 部分认可（如约90%但有少量修改）/ `0` 未认可；可记录任意认可度百分比（如 25%）；`∅` 待确认。

**C2 自动闭环采集**（保证确认不因缺失反馈而中断）：

| 来源 | 触发条件 | 取值 |
|---|---|---|
| `landing` | 成果已在本地落地（保存/执行完成且使用者未撤销） | 视为 100% 认可 |
| `user` | 使用者显式返回认可度 | 按返回值 |
| `auto_timeout` | 发出确认请求后 24 小时未响应 | 默认视为认可 |
| `auto_confirm` | 主动再次确认后仍未响应 | 采信默认认可 |

- 第二轮是使用者对**真实反馈**的解读，不是生成阶段对受众认可的预测，不要求研究者直接调查受众；
- **落地即确认**：成果被实际保存/执行且未被撤销，是认可的最强隐式信号，无需另行询问；
- **待确认不等于失败**：未获足够反馈时按上述自动闭环给出默认值，不中断流程；延迟反馈可回填并覆盖默认值；
- 使用者显式返回与自动默认值分开统计（显式认可率 vs 闭环认可率）；报告应披露各来源占比。

**结果状态：**

| 状态 | C1 | C2 | 含义 |
|---|---|---|---|
| S0 | 0 | — | 未采用 |
| S1 | 1 | ∅ | 已采用，待确认 |
| S2 | 1 | < 0.5 | 已采用，未获认可 |
| S3 | 1 | ≥ 0.5 | 已采用并获认可（含部分认可） |

## 4. 计分与报告

### 4.1 结果状态统计

| 指标 | 定义 | 说明 |
|---|---|---|
| 直接采用率 | 无介入即采用 / 全部任务 | 初稿质量基线 |
| 介入后采用率 | C1=1 / 有介入任务 | 介入是否带来可采纳成果 |
| 第二轮完成率 | 有C2结果 / C1=1任务 | 反馈回填完整度 |
| 已确认认可率 | C2=1 / 有C2结果任务 | 已确认样本中的认可比例 |
| 平均介入量 | ΣI / 任务数 | 每任务介入成本 |

> 注意区分**第二轮完成率**与**已确认认可率**，二者分母不同，混用是常见错误。

### 4.2 HCLR核心指标

```text
HCLR = 模型输出Token（或字符）总和 / 使用者介入Token（或字符）总和
个人汇总: HCLR(u|m,d,T) = ΣO / ΣI
```

- **分子O**：任务事件内模型全部输出Token之和（含O0、O1及中间轮次）；
- **分母I**：使用者介入Token之和（**不含初始任务描述**，只统计针对输出的反馈/纠正/约束/方向调整）；
- 双重确认（C1/C2）保留为**结果状态记录**（S0–S3），不进入公式；

> 该指标测量"输出规模/介入规模"的杠杆关系，不测量输出质量、认知投入或社会认可；与结果状态统计联合解读。

### 4.3 周期与缺失处理

- 默认以自然月为观察周期，可自定义；
- 换模型/领域/受众时标记断点；
- 任务数<10时只展示原始记录，不展示趋势；
- 待确认不计0；提供乐观（全部视为认可）/保守（全部视为未认可）上下界；
- 待确认比例>30%时，第二轮相关指标标注"不可靠"。

### 4.4 排行榜条件（仅社区场景）

跨人比较**只在严格条件下**允许：统一模型与版本、统一任务集与初始输出、统一介入量口径、结果状态由第三方或社区复核、完整交互记录可审计、禁止选择性记录（必须包含失败任务）、异常结果复核。

## 5. 重要边界

- HCLR是**自我评估参考**，不是客观真理标准；
- 不是人的一般智力或总体认知水平量表；
- 不是AI使用能力的唯一评价方法；
- 主要用于同一使用者的**纵向自我比较**，不宜作为跨人绝对排名；
- 不宜作为招聘、淘汰、绩效排名等高风险裁决工具；
- 曲线上升只能作为稀疏介入能力变化的**参考**，不能直接声称证明认知水平提升；曲线下降可能来自任务变难、模型变化或受众变化。

### 已知局限

1. **分母不测认知投入**：介入量只测显性形式；
2. **共同方法偏差**：所有状态确认由同一使用者完成，第二轮是使用者对反馈的解读；
3. **选择偏差**：成功/重要任务更容易被补录第二轮；
4. **无法完全归因**：O0→O1的改变不必然全部由人类介入造成（模型随机性）；
5. **可博弈性**：使用者可能通过选任务、压缩表达、选择性记录虚高分数。

## 6. 隐私与数据

- 记录可能包含商业机密、个人信息、客户数据；
- **本地优先**：记录默认保存在使用者本地，不上传任何服务器；
- 数据属于使用者，可随时删除、导出；
- 任何聚合、匿名化或第三方使用（如模型厂商优化）需单独授权协议，明确用途、期限、可撤销性与贡献归因；
- 模型厂商应区分：即时"好/坏"按钮 ≠ 第一轮采纳确认 ≠ 第二轮受众结果确认；不能把介入后的优秀成果全部归因于模型。

## FAQ

- **谁适合用HCLR？** 经常使用AI产出交付物、想观察自己判断对模型输出影响的人。
- **怎么开始？** 用2–4周真实工作记录任务事件（O0→介入→O1→C1→C2），完整协议见方法稿。
- **分数代表什么？** 在特定模型、任务和周期下，你的显性介入杠杆参考值，不是智力分数。
- **HCLR是已验证的测量吗？** 不是。当前所有分数为实验性参考，尚未完成大规模信效度验证。
- **能用于招聘或绩效吗？** 在信度、效度与抗博弈能力建立前不建议。
