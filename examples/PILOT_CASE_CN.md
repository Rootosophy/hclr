# HCLR 实证案例：对话内嵌采集（Pilot）

> 版本：2026-09-07 ｜ 模型环境：DeepSeek v4 flash（pilot-001~005）/ v4 pro（pilot-006~010）

## 背景

HCLR方法稿公布后，为获取真实实证数据，设计了**对话内嵌采集**方式：直接把AI助手对话作为任务事件来源。使用者无需额外填表，统计完全自动。

## 方案设计

| 要素 | 定义 |
|---|---|
| 任务事件 | 一个主题会话（从提出需求到成果确认） |
| 模型环境 m | 绑定的大模型（pilot-001~005：DeepSeek v4 flash；pilot-006~010：DeepSeek v4 pro）；AI助手为执行/呈现层，不进入m参数 |
| O0 | 助手首轮输出 |
| h | 使用者的介入消息 |
| O1 | 介入后的输出 |
| O（分子） | 任务事件内模型输出Token（或字符）总和，含全部生成轮次 |
| I（分母） | 使用者介入Token（或字符）总和，**不含初始任务描述** |
| HCLR | O / I（输出/介入杠杆率） |
| C1（第一轮确认） | 结果状态：adopt / partial / reject |
| C2（第二轮确认） | 结果状态：approved / partial / rejected / pending（或自定义采纳率 pctN）；来源：user（显式）/ landing（落地即确认）/ auto_timeout（24h默认）/ auto_confirm（采信） |

## 运作流程

1. 每个主题会话结束 → 助手请求C1（使用者一行回答）；
2. P由助手建议、使用者确认；
3. 结论性输出 → 助手请求C2；成果本地落地（保存/执行且未撤销）即视为100%认可（landing）；请求后24小时无响应默认认可（auto_timeout），主动再确认仍无响应采信（auto_confirm）——确认不因缺失反馈中断；
4. 每10个任务或每周生成汇总报告；
5. 原始记录本地存储（不入公开仓库，保护隐私）。

## 当前快照

```text
任务数: 10
HCLR = ΣO / ΣI = 21595 / 1033 = 20.91
分子O（模型输出chars总和）: 21595 | 平均每任务: 2160
分母I（介入chars总和，不含任务描述）: 1033 | 平均每任务: 103
结果状态:
  介入后采纳率（C1含部分）: 10/10 = 100%
  显式认可率（source=user, C2>=0.5）: 4/5 = 80%
  闭环认可率（含auto, C2>=0.5）: 4/5 = 80%
```

> 说明：O/I 来自 Hermes 会话数据库的真实消息统计（O=assistant文本字符总和，I=user介入字符总和、不含初始任务描述）。pilot-001~005 使用 deepseek-v4-flash，pilot-006~010 使用 deepseek-v4-pro；C1 已全部确认（10/10 采纳，含 pilot-001 partial）。pilot-001~005 为方法文档类成果、尚无 C2（按自动闭环协议，其确认请求超时后将默认 closed，不再悬挂）；pilot-006~010 已完成 C2（approved×2、partial×2、pct25×1），全部为使用者显式确认（source=user）。pilot-007/008/010 无介入（I=0），HCLR 未定义（显示"-"）——单轮输出即被采纳、未触发修正；pilot-010 采纳率仅25%，用户认为文案过于正式、自行改写口语化版本定稿。

## 意义

- **零负担验证**：使用者仅在会话结束时回答一行C1，P确认也是一句话；
- **真实数据**：O、I、C1、C2均为真实对话记录，非模拟数据；
- **直接回填论文**：数据积累后，论文第6/7章从"验证计划"改写为"初步验证结果"；
- **反事实控制**：统一口径（chars）；pilot-001~005 同用 v4 flash、pilot-006~010 同用 v4 pro，各阶段内模型一致，满足纵向比较条件。

原始记录保存在本地 `pilot-data/`（符合LICENSE：不公开使用者的完整对话记录）。

## 数据脱敏规则（examples 强制）

examples/ 下所有公开文档的数据在生成/更新前**必须**执行脱敏，未通过不得发布：

1. **公司/组织/品牌名**：不得出现（企业名、品牌名、业务线名一律泛化或删除）；
2. **第三方名称**：供应商/服务商/平台名一律泛化为"服务商/供应商/平台"；
3. **人名**：真实姓名与"姓+职务"组合一律移除，替换为角色（如"领导"）；
4. **金额与合同**：具体金额与费用结构不得出现，改为相对描述（如"平台授权费为年付"）；
5. **内部信息**：内部项目代号（如会议纪要文件名）、路径、内部策略不得出现；
6. **可保留**：O/I 数值、HCLR、C1/C2/状态、领域（泛化后）与脱敏后的介入表达示例——用于方法复现与验证；
7. 发布前须做敏感词扫描（公司名/供应商/人名/金额/代号），任一命中即须先脱敏。
